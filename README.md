
# estatlab

**Laboratório de Exercícios Estatísticos**

Repositório dedicado ao estudo e à resolução de exercícios de Estatística, com enunciados, desenvolvimento matemático, implementações em R e interpretação dos resultados em notebooks Jupyter.

Os conteúdos são organizados por áreas da Estatística, abrangendo desde os fundamentos até métodos avançados.
